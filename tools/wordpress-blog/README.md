# Blog Sébastien Goudon (WordPress avi-fidelio)

Articles storytelling / GEO publiés automatiquement tous les deux jours.

- `articles/` : un fichier HTML par article, avec un en-tête `<!-- title / slug / excerpt / angle -->`.
- `publish.py` : envoie un article sur WordPress (`WP_URL`, `WP_USER`, `WP_APP_PASSWORD`).

Les angles tournent dans l'ordre A → B → C → D (voir le champ `angle` du dernier article) :

- A : Tribune — la technologie au service du commerce de proximité et du pouvoir d'achat.
- B : Parcours — d'autodidacte à créateur d'applications et d'entreprises.
- C : Vision business — terrain, immobilier (sous-location) et numérique.
- D : Cas pratique — Fidelio, logiciels SaaS, hébergement courte durée.
